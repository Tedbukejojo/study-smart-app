# Study Smart App

Aplicativo Android desenvolvido em Kotlin para ajudar estudantes a organizar a rotina de estudos de forma prática e inteligente.

## ✨ Funcionalidades planejadas

- 📝 Anotações para registrar ideias, resumos e conteúdos importantes.
- 🗺️ Criação de roadmap de aprendizado para acompanhar metas e progresso.
- 📅 Integração com o Google Agenda para sincronizar eventos e lembretes de estudo.
- 📱 Interface moderna construída com Jetpack Compose.
- 🧱 Arquitetura MVVM com persistência local usando Room.

## 🛠️ Tecnologias

- Kotlin
- Android Studio
- Jetpack Compose
- MVVM
- Room
- Google Calendar API
- GitHub Actions para CI

## 🚧 Status do projeto

Em desenvolvimento como projeto de estudo e prática de desenvolvimento Android com Kotlin.
